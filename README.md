# Airbnb Dashboard — Tableau

> Exploring the patterns behind Airbnb listings and guest reviews.

An interactive Tableau dashboard built using Airbnb NYC data to explore listing characteristics, host information, neighbourhoods, and review ratings through data visualization.

## Analysis

- Explore Airbnb listings by neighbourhood and property type.
- Analyze room types and listing characteristics.
- Examine host registration trends over time.
- Explore guest review ratings and rating categories.
- Visualize patterns using interactive filters, parameters, and sets.

## Visualizations

- Bar Charts
- Line Charts
- Area Charts
- Pie Charts
- Stacked Bar Charts
- Interactive Filters & Parameters

## Tools

**Tableau** · **Data Analysis** · **Data Visualization**

## Objective

Turn Airbnb listing and review data into meaningful insights through interactive visualizations and exploratory analysis.
